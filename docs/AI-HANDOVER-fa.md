## اصلاح بازخورد پنل — ۲۰۲۶-۱۰-۳۱ (پس از 789c734)

درخواست مالک: حذف رکوردها، تاریخ شمسی، ارقام فارسی، دسترسی مستقیم به تصاویر غذا، فوتر فرم، توضیح تک‌خطی تمام‌عرض، حذف فیلد مسیر تصویر گروه و breadcrumb با عنوان کوچک‌تر. همه روی معماری موجود اجرا شدند؛ فرانت‌اند مشتری، تنظیمات مالک، schema و قرارداد JSON API تغییر نکردند.

- کنار ویرایش هر غذا دکمه «تصاویر» وجود دارد. فرم بارگذاری و جدول تصاویر فقط در صفحه مستقل Images با foodId قرار دارند؛ دیگر برای رسیدن به تصاویر لازم نیست فرم غذا را ویرایش کنید.
- عملیات حذف POST و AntiForgery دارد؛ تأیید مرورگر، کنترل مجوز و وابستگی سمت سرور و Audit اضافه شدند. مدیر کاتالوگ/کارمند/دسترسی شعب را حذف می‌کند؛ کارمند فقط ظرفیت بدون مصرف شعبه خودش را. حذف مدیر، لاگ‌ها و ظرفیت دارای رزرو/فروش مجاز نیست؛ حذف آبشاری وجود ندارد.
- تاریخ‌های ظرفیت و گزارش‌ها شمسی‌اند؛ زمان گزارش به تهران نمایش داده می‌شود. تاریخ ظرفیت با قالب سال/ماه/روز شمسی وارد و با PersianCalendar اعتبارسنجی می‌شود. DateOnly و UTC ذخیره‌شده تغییر نکرده‌اند.
- اعداد نمایشی و ورودی عدد/ساعت فارسی می‌شوند؛ PersianFormValueProvider فقط فیلدهای عدد/ساعت فرم Admin را برای model binding نرمال می‌کند. رمز و متن آزاد تغییر نمی‌کنند. توضیحات تک‌خطی col-12، دکمه‌های فرم در نوار جدا با بوردر بالا، عنوان کوچک‌تر و breadcrumb پیاده شدند.
- گروه غذایی فقط Browse و پیش‌نمایش تصویر دارد؛ مسیر قبلی هنگام ویرایش بدون فایل از دیتابیس حفظ می‌شود.

اعتبارسنجی: Build بدون هشدار/خطا، ۴۰ تست موفق و یک تست SQL اجرا‌نشده؛ syntax دو فایل JS و diff check موفق. HTTP با InMemory ثبت ظرفیت با ارقام و تاریخ شمسی، حذف با CSRF/Audit، جلوگیری از حذف مدیر و redirect خارجی را بررسی کرد. تست‌های واحد تاریخ کبیسه/مرز روز تهران، وابستگی حذف و محدودیت شعبه را پوشش می‌دهند. تست SQL واقعی اجرا نشد. مرورگر Playwright موجود نبود و دانلود آن فایل ناقص داد؛ تست بصری/تعامل مرورگر تأیید نشده است.
