# تنظیمات بک‌اند

فایل `src/AbibiFood.Api/appsettings.json` فقط گزینه‌های غیرحساس و connection خالی دارد. secretها از User Secrets در توسعه یا متغیر محیطی در production می‌آیند:

- ConnectionStrings__DefaultConnection
- Jwt__Key (حداقل ۳۲ بایت؛ خارج Git)
- Jwt__Issuer / Jwt__Audience / Jwt__Minutes (پیش‌فرض ۳۰ دقیقه)
- AllowedOrigins__0 و موارد بعدی برای CORS
- Bootstrap__Email و Bootstrap__Password فقط هنگام ایجاد مدیر اولیه

appsettings.Development.json سطح log را دارد. Messages.fa.json منبع فعلی چند پیام عمومی با reloadOnChange است؛ تمام متن‌های DTO/Controller/View هنوز متمرکز نشده‌اند. تنظیمات مدیریتی فعلی همان داده‌های شعبه، منو، قیمت، ساعت، ظرفیت و دسترسی‌اند؛ جدول تنظیمات عمومی دلخواه هنوز اضافه نشده است.

Cookie فقط Secure/HttpOnly است؛ برای توسعه نیز HTTPS لازم است. JWT در فایل فرانت قرار نمی‌گیرد. ساعت ذخیره لاگ UTC و مبنای روز ظرفیت Asia/Tehran است؛ DateOnly روز را از زمان جدا می‌کند.

لاگ SQL هنگام سالم‌بودن دیتابیس ثبت می‌شود؛ اگر خود SQL قطع باشد، middleware فقط fallback لاگر میزبان دارد. تضمین بازیابی خطاهای دوره قطع SQL نیازمند طراحی صف/فایل پایدار و سیاست نگهداری است و هنوز انجام نشده است.

اعتبارسنجی سمت مرورگر فرم‌های Razor با JustValidate محلی انجام می‌شود؛ مرجع نهایی اعتبارسنجی همچنان DataAnnotations و CatalogService سمت سرور است.

## فونت بک‌اند

از ۲۰۲۶-۱۰-۳۱، خانواده وزیر و وزن‌های ۴۰۰/۵۰۰/۷۰۰ در `wwwroot/assets/css/vazir.css` متمرکز هستند؛ Layout مشترک آن را بعد از admin.css با نسخه cache بارگذاری می‌کند. فایل‌های محلی و مجوز Vazir نسخه 30.1.0 در `wwwroot/assets/fonts/vazir/` هستند. هیچ درخواست CDN برای فونت لازم نیست. Hasti فقط برای فرانت‌اند است و در Layout پنل استفاده نمی‌شود.

## بارگذاری تصویر و ظاهر پنل

محدودیت‌های فایل در `ImageUploadStore`: حداکثر ۵ مگابایت برای هر تصویر؛ سقف درخواست ۵ مگابایت به‌اضافه ۶۴ کیلوبایت برای multipart. فقط MIME و امضای PNG/JPEG/WebP پذیرفته می‌شود؛ SVG مجاز نیست. نام اصلی فایل برای ذخیره استفاده نمی‌شود. این کنترل، اسکن بدافزار یا decode کامل تصویر نیست.

فایل در `src/AbibiFood.Api/wwwroot/uploads/catalog/` ذخیره و از `/uploads/catalog/{name}` عمومی خوانده می‌شود؛ در SQL فقط مسیر ثبت می‌شود. پوشه uploads در Git نادیده گرفته شده است. حساب اجرای برنامه نیاز به مجوز نوشتن در همین پوشه دارد. فایل‌های قبلی هنگام جایگزینی خودکار پاک نمی‌شوند تا مرجع احتمالی دیگر از بین نرود؛ سیاست پاکسازی فایل بی‌مرجع هنوز پیاده نشده. شکست ذخیره رکورد، فایل تازه همان درخواست را حذف می‌کند؛ crash بین دیسک و SQL می‌تواند فایل بی‌مرجع بگذارد.

پیام‌های ImageSize/ImageFormat/ImageRequired در Messages.fa.json هستند. رنگ‌های پنل از متغیرهای `--admin-*` در admin.css قابل تغییرند. محدودیت‌ها فایل‌محورند و صفحه تنظیمات مدیریتی برای آن‌ها ساخته نشده است.

## نمایش فارسی و پیام‌های حذف

منبع تبدیل تاریخ `PersianDisplay` با PersianCalendar استاندارد .NET است؛ منطقه نمایش گزارش Asia/Tehran و ذخیره لاگ UTC باقی است. ورودی تاریخ شمسی متن با قالب سال/ماه/روز است؛ تقویم گرافیکی جدید نصب نشده. اعداد فرم و ساعت با ValueProvider محدود به Admin نرمال می‌شوند؛ ارقام URL، hidden، option value و قرارداد API تغییر نمی‌کنند.

پیام‌های عمومی حذف/تأیید و تاریخ نامعتبر در Messages.fa.json هستند. متن قواعد وابستگی کاتالوگ مطابق قرارداد فعلی در CatalogService قرار دارد؛ تمرکز کامل همه پیام‌های قدیمی/جدید هنوز انجام نشده است. اندازه عنوان و فوتر در admin.css با .page-title و .form-footer تنظیم می‌شود.
