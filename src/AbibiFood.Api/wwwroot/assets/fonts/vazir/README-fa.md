# فونت وزیر برای بک‌اند آبی‌بی

فایل‌های اصلی Vazir نسخه 30.1.0 ساخته صابر راستی‌کردار، بدون تغییر یا تبدیل، برای میزبانی محلی پنل نگهداری می‌شوند. مجوز همراه در OFL.txt است.

منبع نسخه ثابت: https://github.com/rastikerdar/vazir-font/tree/v30.1.0

وزن‌های ۴۰۰، ۵۰۰ و ۷۰۰ در assets/css/vazir.css تعریف شده‌اند. پنل برای دریافت فونت به CDN وابسته نیست. فونت Hasti فقط برای فرانت‌اند مشتری است؛ فایل‌های قدیمی آن در این مخزن حذف نشده‌اند ولی در Layout پنل بارگذاری نمی‌شوند.
